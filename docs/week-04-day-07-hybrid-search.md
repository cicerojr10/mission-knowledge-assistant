# Semana 4 — Dia 7
## Busca híbrida com Reciprocal Rank Fusion

## Objetivo

Combinar os resultados da busca textual e da busca semântica sem remover ou modificar os endpoints existentes.

O novo fluxo deverá produzir um ranking híbrido usando Reciprocal Rank Fusion — RRF.

## Problema

A busca textual e a busca semântica possuem características complementares.

```text
busca textual
→ termos exatos
→ códigos
→ siglas
→ correspondência auditável

busca semântica
→ paráfrases
→ intenção
→ vocabulário diferente
